Neptune

  • Creating a persistent memory layer for robotic deployments, aggregating context data (records, history, regulations) with physical data (MCAP files + ROS + URDF + logs etc). Like supermemory.ai but for robots. With more deployment data, the memory is automatically updated + can be used as a data flywheel.
  • Memory is aimed to be used for downstream applications (LLM agents, VLA policies, simulators, eval/training pipelines and deployment/compliance tooling).
  • Memory system = bi-temporal claim graph + episodic/spatial memory with immutable evidence and revision/invalidation semantics.

Drone VLM System

  • Allows you to ask open-ended semantic questions while the drone is flying (“ChatGPT for drone video”), very applicable to industry + makes monitoring tools + surveillance process more accessible to non-technical operators.
  • Qwen3-VL-2B as pretrained base (4bit mode).
  • Frozen vision tower initially.
  • Image to language merger/projector + LoRA adapter is trained in Qwen’s attention and MLP layers.
  • Completion-only supervised fine tuning on structured aerial tasks.

Drone Aerial Detection + Tracking

  • Drones are great for surveillance / detection deployments but it’s hard to run advanced models on them because of limited onboard compute and battery concerns. I sought to build the lowest cost and most efficient onboard system possible.
  • Fine-tuning of YOLO26n on VisDrone for compute-constrained on-board detection.
  • Targeted MaixCAM2/AX630C inference; switchable ByteTrack and BoT-SORT tracking (depending on drone movement, if it’s just hovering vs moving).
  • This was the basis for my drone VLM project, which extended it on the same codebase.

World Action Model Data Survey

  • Over 200 downloads in just over a month of publication.
  • World action models depend on training data that record agent-environment causality. Therefore, we mapped the current landscape by data through the lens of causal completeness, distilling it into three key tiers.
  • This is followed by an analysis of the saturation of the data collection economy, and discusses the problem of 'scaling in the dark' -> there is a lack of proper benchmarking / taxonomy that measures how well a dataset actually improves model performance.
